# DonaBe - Uma plataforma para encontrar instituições de caridade perto de você

O DonaBe é uma plataforma web que tem como principal objetivo ajudar doadores a encontrar instituições de caridade perto de onde estão, reunindo num só lugar as instituições cadastradas, o que cada uma precisa e como ajudar. É o projeto da disciplina de Programação Orientada a Objetos.

A plataforma está sendo desenvolvida com foco:

- Busca de instituições por proximidade
- Cadastro de instituições pelos seus gestores
- Necessidades das instituições e intenções de doação
- Interface simples, para quem quer ajudar e para quem representa uma instituição

Hoje o repositório tem o ambiente de desenvolvimento configurado, o banco de dados modelado e o login com o Google prontos. As funcionalidades começam a ser construídas a partir daqui.
