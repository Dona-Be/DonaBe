
# Tipos de Issues

Escolha o tipo que melhor descreve o que você precisa. Isso ajuda a equipe a priorizar e responder mais rápido.

## Bug

Use quando algo no DonaBe não funciona como deveria.

Exemplos: botão que não responde, informação errada exibida, login que não conclui, funcionalidade quebrada, etc.

[Ver todos os bugs reportados](https://github.com/Dona-Be/DonaBe/issues?q=is%3Aissue+label%3ABug)

## Qualidade de Código

Use para reportar qualquer fluxo de código que esteja confuso ou complexo demais, discordância com boas práticas ou melhorias gerais de código que não alterem sua funcionalidade.

[Ver todas as issues de qualidade de código](https://github.com/Dona-Be/DonaBe/issues?q=is%3Aissue+label%3A%22Qualidade+de+C%C3%B3digo%22)

## Performance

Use quando o site ou a API apresentam lentidão, travamentos ou carregamento demorado.

[Ver todos os problemas de performance](https://github.com/Dona-Be/DonaBe/issues?q=is%3Aissue+label%3APerformance)

## Interface

Use para problemas visuais como elementos desalinhados, textos cortados, cores/contraste inadequados ou fluxos confusos de navegação.

[Ver todos os problemas relacionados a Interface](https://github.com/Dona-Be/DonaBe/issues?q=is%3Aissue+label%3AInterface)

## Documentação

Use para reportar erros, informações desatualizadas, falta de clareza ou ausência de documentação necessária em qualquer lugar do repositório.

[Ver todas as issues de documentação](https://github.com/Dona-Be/DonaBe/issues?q=is%3Aissue+label%3ADocumenta%C3%A7%C3%A3o)

## Nova funcionalidade

Use para propor funcionalidades completamente novas que ainda não existem no DonaBe.

[Ver todas as funcionalidades solicitadas](https://github.com/Dona-Be/DonaBe/issues?q=is%3Aissue+label%3A%22Nova+funcionalidade%22)
